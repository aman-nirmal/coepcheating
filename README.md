# COEP Notices Gateway

A clean, responsive portal linking and redirecting visitors to the official COEP Technological University Notices page:
👉 **[https://www.coeptech.ac.in/facilities/notices-2/](https://www.coeptech.ac.in/facilities/notices-2/)**

## 🚀 Live Server
- **Local URL:** [http://localhost:3000/](http://localhost:3000/)

## 🛠 Features
- Instant click-through button to official notices
- Built-in 3-second auto-redirect with pause/resume controls
- Meta refresh header fallback for non-JS / search bot crawlers
- Canonical link pointing directly to the official COEP notices domain
