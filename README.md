# COEP Cheating / MPASM Gateway

A lightweight, high-performance web gateway redirecting to:
👉 **[https://mpasm.netlify.app/](https://mpasm.netlify.app/)**

## 🚀 Live Server
- **Local URL:** [http://localhost:3000/](http://localhost:3000/)

## 🛠 Features
- Direct instant redirect via HTML `<meta http-equiv="refresh">` and client-side JavaScript `window.location.replace()`
- Visual countdown with pause/resume support
- Canonical URL pointing to `https://mpasm.netlify.app/`
